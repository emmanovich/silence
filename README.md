
# Ancient Calendar Converter

Ancient Calendar Converter is a Python application that demonstrates date conversion between several historical calendar systems.

The project provides a compact reference of calendar traditions and generates approximate representations of dates across different civilizations.

## Supported Calendars

- Gregorian
- Julian
- Islamic (Hijri)
- Mayan Long Count
- Hebrew
- French Republican

## Features

- Calendar conversion
- Historical calendar catalog
- Date comparison
- Export to text
- Conversion statistics

## Example

```
Input Date

2026-07-23

Gregorian

23 July 2026

Julian

10 July 2026

Islamic

10 Safar 1448 AH

Mayan

13.0.14.13.9

Hebrew

9 Av 5786
```

Run

```bash
python main.py
```
